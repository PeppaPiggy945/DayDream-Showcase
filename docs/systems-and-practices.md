# 其它系统与工程实践

## 记忆系统

长篇叙事的 token 不随章节数线性增长——这是同类项目中少见的保障。

**遗忘曲线四区衰减：**

```
active   精细保留
  ↓
fading   压缩为摘要（LLM consolidation）
  ↓
labile   概率丢弃，或概率闪回
  ↓
core     永久保留
```

- `active` 记忆精细保留；`fading` 被 LLM 压缩为摘要；`labile` 概率丢弃或闪回；`core` 永久。
- 离开视野的角色状态**惰性冻结**（offscreen collapse），重新出现时由 LLM **重建补述**。

两条学理线索：Ebbinghaus 遗忘曲线的直接工程化，以及互补学习系统理论（海马体 → 新皮层巩固）的近似——fading 记忆由 LLM 压缩为摘要再"换出"，与记忆巩固的计算模型同构。

## 持久化

- **SQLite 权威介质**：变量、编年史、prompt、trace 四表，全部**按进度索引**；
- **原子快照** + **WARM 续跑** + **存档租约**；
- **启动是事务性的**：失败按逆序 abort，可重试；
- 运行时资源**单一所有权**，每个后台任务声明停机策略；消费型任务满足"取消后可重投"契约，checkpoint 必落盘。

## 查询层（CQRS）

- 六种 DataSource；
- **live 视图与落盘视图按运行时身份自动切换**——正在跑的存档读内存，跨存档读强制走持久层；
- 命令侧（模拟）与查询侧（六种 DataSource）分离。

## 战斗 / 效果体系

`basic_combat`（9,001 行）+ `basic_monster`（450 行）覆盖：

- 攻防**两段式**结算（先判定命中 / 闪避，再计算伤害与减伤）；
- **图鉴–持有**分离（怪物模板 vs 角色掉落物）；
- 维度渲染（数值明细通过 `outputs` 声明，按消费者密度取用）；
- **自由文本攻击**原则：玩家 / LLM 用自然语言描述动作，代码负责将其映射到数值与结算，LLM 只负责描写。

截图中的战斗编年史可见：`BROADCAST` 条目携带完整结算明细（攻击值、各乘数、防御值、剩余生命），`ACTION` 条目是 LLM 生成的战斗描写——**算账与描写分离**。

## 涌现实证

- **走错的角色**：一次仿真中 LLM 地图匹配失误把角色导到了别人家。系统没有纠错机制，角色自己发现、自己解释（"下雨天脑子一抽走错楼了"），发展出整场最好的剧情。
- **密室的认知碰撞**：4 个历史角色 127 条事件的圆桌对话，只用 5 个插件的最小集跑出，验证架构最小完备性。角色只收到信息核，各自的不知情催生了真实的认知碰撞（嬴政通过对话改变认知，而非剧本设定）。

这两件事说明：**信息不对称不是缺陷，是叙事引擎的燃料。**

## 工程制度（8 月起）

| 制度 | 内容 |
|---|---|
| 批次流程 | 每批次 spec → plan → TDD → 独立复审 → `--no-ff` 合并 |
| 合并前彩排 | 大批次合并前必须在临时 worktree 跑组合测试 |
| 性能先测基线 | 优化前先跑基准，砍在真正流血的地方 |
| AI 互审 | AI 写代码、AI 互审，**驳回记录全部落盘** |
| AST 架构测试 | 依赖单向规则由测试守护，不靠自觉 |

两个真实收获：

1. **合并前彩排**抓到过"两侧单测全绿、组合后 18 个失败"的连接泄漏——单侧验证无法覆盖交叉缺陷。
2. **性能基线**发现 SQLite 每条记录新建连接的代价是连接复用的 **55 倍**——如果凭直觉优化，很可能优化错地方。

## 测试与质量基线

| 指标 | 实测值 |
|---|---|
| 测试用例 | 3,078 |
| 测试代码 | 46,013 行 / 215 文件 |
| 分类 | `unit` / `integration` / `contract` / `e2e` |
| 特性 | 无 live-LLM 依赖、无 skip、无 warning |

```
tests/unit          内核正确性、数据管道、状态机、上下文渲染
tests/integration   进程内组件集成
tests/contract      接口契约
tests/e2e           应用边界的生命周期覆盖
```

此外还有独立进程 runner（每个测试文件起一个全新 pytest 子进程）作为合并 / 夜间门禁，用于暴露模块级状态污染。
