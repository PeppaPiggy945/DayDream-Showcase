# 与并行 / 分布式领域的关联

> 需要诚实说明：这个项目**不是先读了分布式论文再实现**——是独立收敛到某个设计后，发现它在成熟领域早有严格表述。
> 这反而是最有价值的验证：**对领域约束的正确思考，最终会落到和几十年演化相同的地方。**

## 映射表

| 本项目中的设计 | 对应的领域概念 |
|---|---|
| `confirmed_progress = min(各 scheduler 进度)`，作为全系统事件排序与持久化水位线 | **Lamport 逻辑时钟**（1978）：不依赖物理时间的全序约定；取 min 即"全系统确认下界" |
| 独立时间线 + 仅交互时 merge | **happens-before 因果序**：只在因果相关点维护顺序，无关进程异步推进；merge ≈ 进入同一一致性域 |
| chronicle 稳定区 / 波动区（水位线前不可变） | **一致性地切面 / 分布式快照**（Chandy-Lamport）的屏障语义；也即 **event sourcing** 的已提交日志 |
| 确认进度驱动的乱序容忍窗 | 流处理中的 **watermark**：承诺"此后不再有更早的事件"，之前的乱序可重整 |
| 单协程写确认进度；GATHER 只读 / EXECUTE 写入 | **单写者原则**（LMAX Disruptor 同款）；数据库的读写分离与有界陈旧读 |
| inbox buffer：追加式日志 + 每消费者独立 mark + GC 取最慢读者位置 | **Kafka 消费者 offset + 日志保留**；内存回收领域的 epoch-based reclamation（不早于最慢读者的宽限期） |
| entity = 独立调度单元，事件异步投递到 mailbox，tick 时消费 | **Actor 模型**：mailbox、无共享、行为调度 |
| 五层生产者–消费者缓冲、跨 scheduler 异步投递 | 流水线化消息传递；每层的竞态窗口被显式建模而非隐式假设 |
| save.db 追加表 + QueryRouter 读写双视图 | **CQRS**：命令侧（模拟）与查询侧（六种 DataSource）分离 |

## 与学术 multi-agent 模拟的关系

**Stanford Generative Agents（Smallville, 2023）** 是回合制、单线程、全局时间步，贡献在 LLM 侧（记忆检索、反思、规划）；本项目的贡献在**系统侧**——并行时间线、信息不对称投递、token 成本工程。两条线**正交且互补**。

| | Smallville (2023) | DayDream |
|---|---|---|
| 时间 | 全局时间步 | 多角色独立时间线 |
| 执行 | 单线程顺序 | 每实体独立 Scheduler |
| 记忆 | LLM 检索 + 反思 | 遗忘曲线 + 巩固 + 离屏冻结 |
| 成本 | 每步全量检索 | 信息密度分离，近似常数 |
| 地图 | 网格 world | 角色状态惰性冻结 + LLM 重建 |

## 记忆系统的学理线索

1. **Ebbinghaus 遗忘曲线**：四区衰减（active → fading → labile → core）是遗忘曲线的直接工程化。
2. **互补学习系统理论**（海马体 → 新皮层巩固）：`fading` 记忆由 LLM 压缩为摘要再"换出"，与记忆巩固的计算模型同构。

## 一点方法论

架构自然收敛到 OS 内核 / 分布式系统的模式，不是抄——是对的。真正要区分的是：

> "因为是标准做法所以正确" vs "因为你理解了本质，而它恰好收敛到标准做法"。

这个项目验证的是后者。从"参考量子力学的独立时间线"这种新奇表述开始，到最终承认"时间在分布式系统中永远只是一个逻辑变量"——新奇感消失不是因为系统变弱了，是因为理解了它的本质。
